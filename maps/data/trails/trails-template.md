# Trail Data Template

Add trail waypoint coordinates here as collected from Google My Maps or GPS.

## Format

```
Trail Name: [Name]
Date: YYYY-MM-DD
Distance: [miles/km]
Elevation Gain: [feet/meters]
Difficulty: [Easy/Moderate/Difficult]

Waypoints:
- 42.883647, -74.441161
- 42.884019, -74.440925
- 42.887513, -74.434961
- [continue...]

Notes:
- Surface type (stone, dirt, etc.)
- Seasonal conditions
- Landmarks along trail
```

## Example

```
Trail Name: Main Loop
Date: 2024-01-28
Distance: 1.5 miles
Elevation Gain: 250 feet
Difficulty: Moderate

Waypoints:
42.883647, -74.441161
42.884019, -74.440925
42.887513, -74.434961
42.886861, -74.434465
42.884434, -74.441279

Notes:
- Stone trail in good condition
- Winter: may be muddy near creek
- Vista point at waypoint 3
```
