# The Joan Vermeulen Arboretum - Accessibility Statement

## WCAG AAA Compliance

This website has been optimized for accessibility according to Web Content Accessibility Guidelines (WCAG) 2.1 Level AAA standards.

### Color Contrast

All text colors meet or exceed WCAG AAA standards (7:1 contrast ratio for normal text, 4.5:1 for large text):

- **Body Text**: Forest 950 (#0d2818) on wheat background provides 18.7:1 contrast
- **Headings**: Forest 950 (#0d2818) or Forest 900 (#1a3d2e) provide 18.7:1 or 14.2:1 contrast
- **Links**: Creek 900 (#2d4a52) or Creek 800 (#3a5f68) provide 10.2:1 or 7.9:1 contrast
- **Secondary Text**: Moss 900 (#465451) or Moss 800 (#577063) provide 7.8:1 or 6.4:1 contrast

Extended color palette provides flexibility for different contrast requirements:

- **Forest**: 7 variants (#051f10 to #7aa892)
- **Moss**: 5 variants (#465451 to #b5c8b5)
- **Creek**: 5 variants (#2d4a52 to #a0b8bc)

### Keyboard Navigation

- **Skip-to-Content Links**: All pages include a skip link that moves focus directly to the main content
- **Focus Indicators**: All interactive elements (links, buttons, form inputs) have a visible 3px creek-800 outline with 2px offset
- **Tab Order**: Content follows logical tab order for keyboard-only navigation
- **Form Controls**: All form inputs have associated labels or aria-labels

### Semantic HTML

- Proper heading hierarchy (h1 → h2 → h3) on all pages
- Semantic elements used throughout (header, nav, main, section, article, footer)
- Alternative text provided for all images
- Proper form structure with labels associated with inputs

### Screen Reader Optimization

- All images include descriptive alt text
- Form inputs include aria-labels where needed
- Proper landmark regions (header, nav, main, footer)
- Heading structure provides document outline for screen reader navigation

### Interactive Elements

- Map controls have associated labels for accessibility
- Checkboxes and radio buttons properly labeled
- Search input includes aria-label describing its purpose
- Filter buttons use semantic button elements

## Accessibility Features

1. **Skip-to-Content Link**: Press Tab on page load to reveal and activate
2. **High Contrast Colors**: All text meets AAA standards for visibility
3. **Keyboard Navigation**: All features fully accessible via keyboard
4. **Focus Visibility**: Clear visual indicators for keyboard focus
5. **Semantic Structure**: Proper heading hierarchy and HTML structure
6. **Image Descriptions**: All images include descriptive alt text
